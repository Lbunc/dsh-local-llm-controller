# Qwen3.6-35B-A3B-UD-TPM-IQ4\_NL（带 MTP，17.26GB）

> 拆分自《本地模型调优全历程终版存档》，编号保留原章节号（§N.x）以便交叉引用；测量方法论见 [../llm-experiment-design/SKILL.md](../llm-experiment-design/SKILL.md)。

> 特性：比Uncensored小 1.16GB、量化更激进（3.9 vs 4.25 bit/param），**带 MTP 头**（`blk.40.nextn.*`）。部分早期结论被本表后续复核修正（首轮误判 + 会话噪声）。

### 3.1 核心发现

- **无 MTP 同配置 \~40 t/s vs 旧版 70-74**（激进低比特解量化开销大）。
- **MTP 带来 +30-40%**：无 MTP util 58-61%（未饱和），MTP 后 48-55%，验证批量有效分摊 GPU 工作。首轮"MTP 无收益"是会话负载误判。

### 3.2 MTP × ncmoe × 上下文最优（2026-08 最终）

- **MTP 模式额外 +\~700MB 显存**（draft 缓冲）→ N20+MTP 上下文极限降到 \~48K（无 MTP 时 96K）；**N22+MTP 恰好补偿 → 96K 可用**。
- 无 MTP 时 N20 @32K long \~35-38；**MTP n=2 后 long \~51、deep 22k \~53、接受率 70.5%**。

| 推荐        | 参数                                                          | 表现                                     |
| --------- | ----------------------------------------------------------- | -------------------------------------- |
| ① 文本速度最快  | `-ncmoe 20 --spec-type draft-mtp --spec-draft-n-max 2` @32K | long \~51、deep \~53 t/s、接受率 70.5%      |
| ② 文本综合上下文 | `-ncmoe 22` + MTP n=2 @98304                                | long \~41-45、deep 88k \~38、无溢出（3× 上下文） |
| 视觉        | ❌ 不可用                                                       | 大图 59.8s（旧版 11.8s）                     |
