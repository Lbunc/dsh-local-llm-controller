# Qwen3.5-9B-Q6\_K（dense，带 MTP，7.16GB）

> 拆分自《本地模型调优全历程终版存档》，编号保留原章节号（§N.x）以便交叉引用；测量方法论见 [../llm-experiment-design/SKILL.md](../llm-experiment-design/SKILL.md)。

> 特性：dense（expert\_count=0），Q6\_K \~6.5GB < 12GB 显存，**带 MTP 头**（`blk.32.nextn.*`，\~40MB）。**思考模式默认开启**，需设 `--reasoning-budget`。

### 4.1 MTP 投机解码（★重大收益）

| 模式                  | short t/s       | 22k 深填充 t/s | 接受率       |
| ------------------- | --------------- | ----------- | --------- |
| 基准                  | 56.7/56.4/56.3  | 52.2        | —         |
| `draft-mtp n=2`     | 85.5/94.3/107.2 | **91.0**    | 72.1%     |
| `draft-mtp n=3`（最优） | —               | —           | 接受率 59.9% |

→ 深填充 +74%、短生成 +67\~90%（n=3 最优，96.8 t/s）；无损（验证失败自动回退）。**9B dense 全 GPU、MTP util 74-78%（未饱和），MTP 大放异彩。**

### 4.2 上下文扫描（MTP n=3）

实际 KV ≈25KB/token（含 SSM 状态，高于理论 16KB）；shared 从 131072 跳升（1036MB），196608 硬溢出（3590MB，38 t/s）。**不掉速极限 ≈ 98304\~114688**。

| C      | short t/s | deep t/s          | shared      |
| ------ | --------- | ----------------- | ----------- |
| 32768  | 79\~107   | 87.6\~91（22k）     | 201         |
| 65536  | 85\~94    | 98.9（52.7k）       | 265         |
| 98304  | 82\~86    | 73.6\~79.4（87.9k） | 326         |
| 114688 | 78\~85    | 57.1（101k）        | 359         |
| 131072 | 59\~64    | 超时                | **1036** ⚠️ |

→ 速度最快 = 32K + n=3（\~88-107，+60%）；综合 = 98304 + n=3（96K，3× 上下文仍远快于无 MTP 的 32K 基准）。
