### 2.1 卸载（-ncmoe）×上下文扫描（干净环境，确认扫描）

| C     | 空闲 shared | short（稳态）t/s | deep t/s（填充）     |
| ----- | --------- | ------------ | ---------------- |
| 40960 | 142       | 66.2         | 64.1（30.8k）      |
| 49152 | 147\~151  | 69.3/81.0    | 72.7/74.3（39.5k） |
| 57344 | 151\~159  | 71.1/82.8    | 69.9/70.7（43.9k） |
| 65536 | 159\~180  | 79.0/84.0    | 69.3/69.8（52.7k） |

→ **57344\~65536 仅掉 \~4-6%**；81920 shared 跳升至 303MB（KV 溢出开始）。取档：追求极限 65536（余量 \~0.5GB，需关后台），稳妥 49152（\~0.8GB），日常保守 32768（用户最终选择）。

### 2.2 ncmoe 扫描历史（决策依据）

- **ncmoe 16\~26**（@21k 长上下文）：N<20 断崖（shared 683\~1714MB → 25 t/s）；N≥20 shared \~170MB → 49\~71 t/s → 选定 **N=20**。
- **三档 @21k**：20 → 74.1 t/s（余 0.8GB）；22 → 71.8（1.6GB）；24 → 69.6（2.5GB）。

### 2.3 掉速曲线（模型特性，任何配置躲不开）

速度 ≈ 74（≤40k）→ 70（53k）→ 63（70k）→ 60（88k）→ 54（119k）t/s（注意力成本 + CPU 专家瓶颈）。配置 C 只在溢出点之后才影响速度。

### 2.4 视觉编码器（mmproj 858MB）

视觉分水岭 **N=24**（mmproj 858MB + 编码期缓冲需 \~1.6GB 余量）：

- 速度最快 = N=24 @32K（大图 11.8s）；综合上下文+速度 = N=24 @96K（大图 15.2s、deep 49.5，无溢出）。

### 2.5 投机解码（MTP/ngram）——不可用

本模型 GGUF（量化）不含 MTP 层，`draft-mtp` 启动即失败（`model doesn't contain MTP layers`）。ngram 投机无收益（draft 几乎不接受，速度无提升）。**当前 GGUF 上投机解码无可用方案。**

### 2.6 最终配置（已恢复）

```
set MOE_MODE=-ncmoe 20
set CONTEXT_SIZE=32768
set REASONING_BUDGET=2048
（其余：-ngl 99 -fa on KV q8_0 -t/-tb 20 -np 1 temp 1.0 top_k 20 top_p 0.95 min_p 0.0；端口 21113）
```
