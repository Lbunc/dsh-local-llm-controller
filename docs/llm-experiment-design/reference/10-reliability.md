# 10 · 可靠性校验、对照组门与存档（第 4 步）

## 4.1 基础校验

- **异常必重测**：非单调、与物理信号矛盾、孤立的低值 → 在干净环境重测（后台负载污染最常见）。
  修正后更新结论；旧数据标注"已修正"保留，不要删除。
- **物理信号 > 速度读数**：显存分配行为是确定性的；t/s 只用来量化掉速幅度，不用来判定溢出。
- **一次只变一个变量**：每个实验只改一个参数，其余全固定；先粗扫找断崖，再细扫定位。
- **测量可重复**：关键点**重复 ≥2 次**；**任何非预期差距需重复 ≥3 次**才算。
  不解释就存档，等于没测。
- **测完必恢复**：杀掉测试子进程、释放端口、确认显存回落，不留脏状态。

## 4.2 ★ 对照组门：要不要重测基线模型

一句话：**重测基线是买"可信度"的成本，必须先过门再付钱。**

| 情况 | 怎么做 | 理由 / 代价 |
|---|---|---|
| **新 harness 或新判分脚本首次投入使用** | **强制跑对照组**（基线模型 + 同题同参同 harness） | 新 harness 的缺陷会伪装成"新模型能力差"；对照组能让假失败同步暴露，一次洗清（`08-measurement.md` 8.3） |
| 要跨模型报"差距" | 优先 **L1 同进程多模型**拿配对值 | 分钟级且噪声极低；替代"逐点重启 server"的高噪声 + 数十分钟 |
| **存档里已有同条件点** | **禁止重测**：直接引用存档值，标注"存档值 + 会话" | 判定"同条件" = **ctx / KV 类型 / 卸载档 / 线程数**四项一致；有一项不同才算新点 |
| 存档值与本轮有差异 | 仅当**超出存档漂移带**才重测；带内直接引用 | 跨会话漂移是已知量，不要用重测去"解决"它（漂移带由本机历史数据确定） |
| 用户没要求、纯粹为保险 | **先问用户**再付成本 | 一轮基线重测的代价可观，属可省则省 |

**报告必写**：

- 本次哪些点是**新测**、哪些是**引用存档**
- 哪个模型当了**对照组**
- 重测基线（若发生）命中了上表哪一行
- 每个带数字的结论所属的**测量层级**（L1 / L2 / L3，见 `08-measurement.md`）

## 4.3 存档格式

- `docs/` 下：报告（方案 / 数据总表 / 结论 / 异常重测记录 / 能力题逐题打分）
- `logs/` 下：原始日志（含完整思考链，供事后复核与还原）
- `scripts/`：可复跑的脚本
- 结构化结果用 JSON 落盘，便于跨会话复用（避免"为了拿回数据重跑模型"）

**与部署解耦**：本 skill 只沉淀**通用实验方法**。最终部署 / 启动产物（服务配置、客户端接入）由部署侧负责，
实验结论写进报告即可，不在本 skill 内重复。

## 可选模块：多模型横向能力对比

> 仅当用户想"多个模型谁更强 / 差距多大"时启用；不改变主流程。

**难点不是测出分数，而是让分数可信**——强模型间差距小，易被噪声淹没。
**核心 = 让差异可复现、可归因。**

### 公平性三条硬规则

1. **同构同参**：同一套判定参数与 ctx / KV / 卸载配置，**唯一变量 = 模型**。
   各模型按自身特性用合适卸载档时，**必须记录并注明**。
   速度部分优先用 **L1 同进程多模型**，不要用"逐点重启 server"。
2. **同题同 prompt**：用 `bank/` 里的冻结题库（`09-capability-bank.md`），
   两模型跑**完全相同的题目、同一份 harness、同一 `max_tokens`**。
3. **程序判分**：test cases / 规则校验 / MC key；**禁止主观打分与手写标准答案**。

### 先过区分度门，再比高低

- 题库本身没有区分度时，结论只能是「**测不出差异**」，不要硬排名次。
- 只有少数差异题时，按 `09-capability-bank.md` 9.4 做**同轴复现检验**，报告 n 是多少。

### 速度差距的两种口径（必须标注）

| 口径 | 含义 | 数值特征 |
|---|---|---|
| **各取最优档** | 每个模型都用自己最优的卸载档 | 更贴近实际部署 |
| **同卸载深度** | 两模型用同一个卸载档 | 更机械、通常数值更大 |

**引用速度差距时必须写明是哪种口径**，否则不可比。

### 关键教训（作为检查项）

1. 题目歧义会制造假差距 → 建库时查题面自洽性（`09-capability-bank.md` 9.5）。
2. 任何非预期差距**重复 ≥3 次**才算。
3. **必须跑对照组**——否则 harness 缺陷会伪装成能力差。
4. 同档时结论就写「**测不出差异**」，不要为了有结论而造结论。
5. 逐题报告，不要只报平均分。
